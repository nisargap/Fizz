    03 / OPEN API

    Send your own data

    Switch any sensor to API mode. Fizz shows its key once, then accepts JSON readings over HTTPS. Each sensor has its own key so you can rotate or revoke it independently.

    curl -X POST https://fizz-zeta.vercel.app/api/ingest \
  -H 'Authorization: Bearer YOUR_SENSOR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"sensor_id":"YOUR_SENSOR_ID","event_id":"sample-001","metrics":{"temperature_c":27.4}}'
